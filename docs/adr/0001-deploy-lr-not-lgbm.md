# ADR-0001: 部署模型选逻辑回归——校准稳定性优先于边际排序收益

- 状态：已采纳
- 日期：2026-10-03（成文 2026-10-04，追溯既有决策）
- 关联代码：`src/creditrisk/models.py`、`src/creditrisk/calibration_repair.py`、`app/main.py`

## 背景

实验矩阵中 LightGBM 的排序指标（AUC/KS）与逻辑回归接近（credit-g 这类
小样本宽特征数据集上提升有限），但两类模型在"输出概率"这件事上性质不同：
树模型的原始分数不是良好校准的概率，且对分布迁移更敏感。

## 决策

部署 **LR（balanced 类权重）+ 后校准**，LightGBM 作为实验对照保留在
训练报告里。理由：

1. 本项目的核心交付是"违约概率"而非排序分——概率要直接喂给审批阈值，
   校准质量（ECE）是第一指标，LR 的线性形式对后校准更友好（实测校准后
   ECE 0.0681，PD 均值偏差 +0.001）；
2. 单样本解释走 coef × WOE，与 SHAP 全局重要性并排展示时口径差异
   可控且已在 README 声明；
3. 线性模型参数量小，分发与回滚成本低。

## 代价

- 排序能力放弃了 LightGBM 的潜在小幅提升（本数据集实测差距在噪声量级）；
- 若未来语料扩到非线性可分的规模，需重新评估——届时校准层协议
  （OOF 择优）不变，仅替换基模型。
