# ADR-0003: 公平性审计做描述性测量，不做再平衡

- 状态：已采纳
- 日期：2026-10-03（成文 2026-10-04，追溯既有决策）
- 关联代码：`src/creditrisk/fairness.py`、`reports/fairness.md`、`reports/fairness_sensitivity.md`

## 背景

personal_status 字段含性别编码，按其分组审计发现显著差距
（demographic parity 差 0.336，女性组批准率 49.2% vs 男性单身组 66.9%）。
下一步自然被问"要不要做去偏"。

## 决策

审计只做**描述性测量**（分组选择率、等机会差异、分组 AUC、三档阈值
敏感性），不做再平衡/去偏/移除受保护属性。理由：

1. 部分差距反映该组实际违约率更高（female div/dep/mar 32.8% vs
   male single 28.8%）——"拉平选择率"与"保持风险口径"存在原理性张力，
   在没有业务方定义公平性目标（Demographic parity 还是 Equal opportunity）
   之前，任何再平衡都是替业务做价值判断；
2. 小样本组（male div/sep n=9）读数噪声大，基于噪声做干预不负责任；
3. 诚实的差距数字 + 敏感性扫描，比一个"看起来公平"的粉饰模型
   更符合本仓库的交付标准。

## 代价

- 模型直接用于真实审批会带来合规风险——README 已显著声明
  "演示级、未做再平衡"，这层边界不允许被移除；
- 去偏（再加权、阈值逐组调整）留作未来带业务约束的工作。
